- `chime`: Five-note harmonic chime synthesized in pure C Major (528Hz healing resonance).

- `whoosh`: Low-pass filtered pink noise sweep simulating a coastal breeze.

- **Mute All Sounds 🔇**: Instantly silences all Web Audio synthesizers with zero state disruption.
- **Hush Mode 🤫**: Suppresses all pop-up celebratory toasts while continuing silent achievement logging.

## 🛡️ Enterprise-Grade Architecture (§4, §16)

Beneath its glossy, bubble-strewn surface lies an uncompromising modern software engine:

1. **Zero Runtime Network Access (100% Offline):**  
   AeroSynergy makes zero outbound HTTP, HTTPS, or WebSocket connections. It contains no telemetry, no analytics, no third-party trackers, and no user accounts. Your data never leaves your machine.
2. **Crash Containment Boundaries (`BubbleBoundary`):**  
   Every feature window is encapsulated in an isolated React Error Boundary. If a feature throws an unhandled exception, it renders an in-character popped-bubble card: *"🫧 Oops! This bubble popped. Our AI is already reimagining it ✨"* with a Dewey illustration and a one-click Retry button. The app itself never crashes.
3. **Namespaced Storage Engine:**  
   State is stored in a structured key-value architecture partitioned by feature namespace (`as365:<featureId>:<key>`), preventing cross-feature contamination.
4. **Hardened Electron Security:**  
   Configured strictly with `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, and an airtight Content Security Policy (`default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'`).
